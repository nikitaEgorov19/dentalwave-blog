# DentalWave Blog - Стоматологический научный журнал

Проект веб-приложения для подачи, рецензирования и публикации научных статей в стоматологической области.

## Особенности

- Подача заявок на публикацию статей через веб-форму
- Административная панель для управления статьями
- Автоматические email-уведомления на всех этапах workflow
- Генерация PDF статей с соблюдением технических требований (А4, Times New Roman, etc.)
- Статусы статей: на модерации, опубликована, отклонена
- Полноэкранный режим редактирования текста и аннотации
- Загрузка и управление статьями

## Технические требования к статьям

- Формат А4, книжная ориентация, все поля по 20 мм
- Шрифт — Times New Roman, 14 кегль, межстрочный интервал 1,5, абзацный отступ 1,25 см
- Выравнивание по ширине, переносы слов отключены
- Заголовок статьи — заглавными буквами на русском
- После пустой строки — аннотация (не более 6 строк) и ключевые слова (не более 6 слов/словосочетаний)
- Основной текст: печатается сплошным блоком с выравниванием по ширине
- Сноски (подстрочные примечания) не допускаются
- Ссылки на литературу даются в квадратных скобках внутри текста: [1], [2, c.115] или [1, 2]
- Список литературы: оформляется после текста с пустой строки. Заголовок «Список литературы:», затем нумерованный список вручную

## Установка и запуск

1. Установить зависимости: `npm install`
2. Запустить сервер: `npm start`
3. Открыть в браузере: `http://localhost:3000`
4. Админ панель: `http://localhost:3000/admin`

## Структура проекта

- `server.js` - основной сервер на Express.js
- `public/` - статические файлы (HTML, CSS, JS)
- `data/` - хранилище JSON файлов со статьями и категориями
- `public/admin.html` - административная панель
- `public/index.html` - главная страница с формой подачи заявок

## API Endpoints

- `GET /api/articles` - получить список всех статей
- `POST /api/articles` - подать новую статью
- `PUT /api/articles/:id` - обновить статью (изменить статус, содержимое и т.д.)
- `DELETE /api/articles/:id` - удалить статью
- `GET /api/articles/:id/pdf` - получить статью в формате PDF
- `GET /api/categories` - получить список разделов
- `POST /api/categories` - добавить новый раздел
- `DELETE /api/categories/:id` - удалить раздел
- `POST /api/verify` - проверка авторизации для админ панели

## Email уведомления

Система отправляет email-уведомления на следующих этапах:
1. При подаче заявки - автору о получении и администратору о новой заявке
2. При публикации статьи - автору об успешной публикации
3. При отклонении статьи - автору с указанием причины отклонения

Для работы email уведомлений необходимо настроить credentials в файле server.js (раздел nodemailer configuration).
